# Cinderline

A dark VS Code color theme ported from [Cinderline for Zed](https://github.com/injty/cinderline): neutral asphalt surfaces, silver text, and muted orange, sage, and terracotta accents.

Select **Cinderline** with **Preferences: Color Theme** after installing the extension.

Object keys and member properties use the editor foreground. Named constants and warnings share bright orange; errors are terracotta. Git additions are green and modifications copper. TextMate and semantic token rules both use upright text. For TypeScript imports, enable semantic highlighting if you want the editor to distinguish a readonly variable from a generic import alias.
